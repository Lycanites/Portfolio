DENKO · 2023–2025

En producción

Aplicación web de entrenamiento mental basada en juegos. Incluye cuatro áreas (memoria, lógica, lectura y análisis), varios modos de juego, una tienda y perfiles de usuario. Fui el desarrollador principal.

DANA

Proyecto personal

Demo disponible

Herramienta para limpiar archivos de Excel y CSV. El usuario sube un archivo con errores y lo recibe ordenado. Todo se procesa en el navegador, así que el archivo nunca se envía a un servidor.

  • Detecta celdas vacías, filas repetidas, espacios sobrantes y números o fechas guardados como texto.
  • Cuando una fecha es ambigua o un valor parece fuera de rango, lo señala sin modificarlo. El usuario decide qué corregir.
  • Procesa los archivos en segundo plano con Web Workers, para que la página no se congele con archivos grandes. Exporta a CSV o Excel con un registro de cambios.
  • Tiene plan gratuito y plan Pro con pagos por Stripe, funciones en Vercel y pruebas automatizadas con Vitest.
